# A LITTLE JOURNEY · for 米高

PID 送給米高（Michael）的歡送電子卡片。

## 修改內容
- 所有照片、留言都在 `data.js`
- 照片放在 `images/`，換檔後改 `data.js` 裡的 `src`
- 留言照表單原文保留，換行用 `\n`

## 部署到 GitHub Pages
1. 建一個新 repo（例如 `for-michael`），把這個資料夾的所有檔案上傳到根目錄
2. Settings → Pages → Branch 選 `main` / `(root)` → Save
3. 幾分鐘後網址會是 `https://<帳號>.github.io/for-michael/`
